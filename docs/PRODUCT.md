# Product and quality standard

The full standing brief lives at the **MyOffice workspace** (parent folder of this repo):

`../docs/PRODUCT.md`

If you only have this frontend clone, the essentials are:

- Mine engineering **ERP/MIS** with **maintenance / work orders** as a core workflow.
- Trust through accurate data, dependable workflows, maintainability, and polished daily UX.
- Use `components/shared/design-system/` — extend shared UI; deliberate loading/empty/error states.
- Work order status map: see `../docs/WORK_ORDERS.md` (or grep `maintenance.py` in backend).

Also read [ENGINEERING_STANDARDS.md](./ENGINEERING_STANDARDS.md) for frontend wiring rules.
